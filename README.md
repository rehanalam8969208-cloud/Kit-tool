# Cyber Photo Toolkit 🕵️‍♂️

Yeh ek Termux tool hai jisme 2 features hain:
1. **Secret Stego**: Photo ke andar chhipa hua message likhna aur padhna.
2. **Pixel Glitch**: Photo ke pixels ko kharab karna aur Key ke through wapas sahi karna.
